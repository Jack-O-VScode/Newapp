# Drop your images here

The site expects these exact filenames:

| File | What it is |
|---|---|
| `logo.png` | The APEX triangle logo. Square, ideally 512x512 PNG with transparency. |
| `review-1.png` | Review screenshot from `aiiyl` |
| `review-2.png` | Review screenshot from `tw1nturb0` |
| `review-3.png` | Review screenshot from `enster3024` |

If a file is missing the site still works — the logo falls back to a drawn
version and missing review screenshots just remove themselves, leaving the
transcribed text.
